# Personal Registry Application

A structured C# console application built to demonstrate core Object-Oriented Programming (OOP) principles, custom data structures, and robust user input validation. This project was developed as part of the **IT Security and Software Testing** program at Högskolan Dalarna.

## 🚀 Features
* **Interactive Menu System:** A dynamic console menu utilizing `while` loops and `switch` cases for seamless navigation.
* **Dynamic Data Storage:** Efficient in-memory data management using generic collections (`List<T>`) to store registry profiles.
* **Custom Data Types:** Implementation of custom structural types including `struct` and type-safe `enum` structures.
* **Input Validation:** Safe user input parsing using `TryParse` methods to prevent runtime crashes and ensure data integrity.

## 🛠️ Technologies & Concepts Used
* **Language:** C# (.NET)
* **Paradigm:** Object-Oriented Programming (OOP)
* **IDE:** Visual Studio
* **Version Control:** Git & GitHub
* **Key Architecture Concepts:** Encapsulation, Generics, Method Overriding (`ToString`).

## 📂 Project Structure
* `Program.cs` - Handles the application runtime logic, console user interface, input validation, and memory management.
* `Person.cs` - Defines the `person` blueprint class, properties, encapsulated attributes, and custom string formatting.
